# building-with-grok-bot
This is a repo in which I showcase my path of building with Grok bot

I am Roberto Zuñiga. This repository is the log for a daily public challenge on X: document what I build with Grok Bot, from day 0 (2026-10-24) until I work at [@spacexsi](https://x.com/spacexsi).

X: [@robzu99](https://x.com/robzu99)

## Layout

- [`days/`](days/README.md) — one file per day, named `day-00.md`, `day-01.md`, and so on.
- [`showcases/`](showcases/README.md) — one folder or file per showcase.
- [`skills/`](skills/README.md) — Grok Bot skills, one folder per skill.
- [`REFERENCES.md`](REFERENCES.md) — every cited repo, with its link and license.
