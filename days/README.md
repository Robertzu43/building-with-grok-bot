# Days

One markdown file per day of the challenge.

## Naming

Files are named `day-NN.md`.

- `day-00.md` is day 0 (2026-10-24).
- The next day is `day-01.md`, then `day-02.md`, and so on.
- `NN` is the day index, zero-padded to two digits (`day-00` through `day-09`).

The first entry is [`day-00.md`](day-00.md). Day 1 is [`day-01.md`](day-01.md). Day 2 is [`day-02.md`](day-02.md). Day 3 is [`day-03.md`](day-03.md).
